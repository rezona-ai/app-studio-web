# 国际化(i18n)实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为分站接入 react-i18next,支持 en/zh/vi/es 四语;语言由主站经 `<html lang>` 驱动,前端 UI 文案全部走 `t()`,后端 error 按 code 兜底本地化。

**Architecture:** 新增 `src/i18n/`(纯逻辑 `config.ts` + i18next 单例 + 四套类型安全词典 + error 映射)。locale 真相源是 `<html lang>`(主站下发),`I18nProvider` 挂载时与 `useHostConfig` 运行期分别调 `i18n.changeLanguage`;组件用 `useTranslation()`,语言变化自动重渲。SSR/首帧确定性用 `en`,挂载后切真实语言(对齐 `useIsDark` 范式),零水合不匹配。

**Tech Stack:** Next.js 16 + React 19 + zustand;i18next + react-i18next;Vitest + jsdom(测试同目录 `*.test`)。

设计稿:`docs/superpowers/specs/2026-06-26-i18n-design.md`。

## Global Constraints

- 代码注释 / 计划 / commit message 一律用**中文**;commit 一句话总结,结尾附 `Claude-Session` trailer。
- **不引入新依赖除 `i18next` + `react-i18next`**;不引入 next-intl、不加路由 `[locale]` 段。
- **不自建语言切换器、不入 persist store、不回写 localStorage**——locale 完全由主站经 `<html lang>` 驱动(分站只读)。
- **回退语言固定 `en`**(i18next `fallbackLng`),`en` 词条必须完整。
- **测试语言固定 `en`**(`vitest.setup.ts` 调 `i18n.changeLanguage('en')`)——现有 UI 多为英文,`en` 词条逐字复制英文源串使现有测试原样通过;少数中文源串的测试改成英文译值。
- **不臆测后端字段**:store 仍只存 `{ code, message }`;本地化在渲染层做,未命中映射回退后端原 `message`。
- **不绕过 basePath**:词典静态打包,不走 HTTP `loadPath`;无新增自身绝对路径。
- **lint 约束**:effect 内禁直接 `setState`(用渲染期 guard);`eslint-disable` 必带 `-- 理由`(中文)。
- **UI 令牌**:本计划不新增视觉元素,沿用既有组件/令牌,仅替换文案为 `t()`。

## 约定(所有抽取任务通用)

### key 命名

- 单一默认命名空间 `translation`,**嵌套对象**,点号访问:`t('chat.composer.send')`。
- 顶层按区域分组:`common.* / workspace.* / chat.* / canvas.* / preview.* / errors.*`。
- 插值用 i18next 双花括号:`t('chat.question.progress', { cur, total })` ↔ 词条 `"第 {{cur}} 题,共 {{total}} 题"`。
- 词典 TS 文件:`en` 定形状(canonical),`zh/vi/es` 标注 `: Messages`(`type Messages = typeof en`)——缺 key 编译期 `tsc` 报错。

### 字符串发现法(逐文件扫描,勿仅靠本计划表)

对每个目标文件,定位**所有用户可见**字面量(中文注释不动):

```bash
# 属性文案
rg -n --pcre2 "(aria-label|placeholder|title|alt|removeLabel|\blabel|\btext|ariaLabel)\s*=\s*[\"'][^\"'{][^\"']*[\"']" <file>
# JSX 文本节点
rg -n --pcre2 ">\s*[A-Za-z\x{4e00}-\x{9fff}][^<>{}\n]{1,80}<" <file>
# 静态配置 / 拼接的展示串(label:/verb:/'...'+变量)
rg -n --pcre2 "[\"'][A-Za-z\x{4e00}-\x{9fff}][^\"']{1,60}[\"']" <file>
```

排除:CSS 类名、`var(...)`、URL、纯技术枚举值(如 `'1024x1024'`/`'png'`/`'mp3'`——这些是 value 不译)、`console.*`/`throw new Error(...)`(内部日志,非用户态)。

- [ ] **Step 4: 实现 `config.ts`**

```ts
// i18n 支持的语言、回退与归一。纯函数,无副作用。
export const SUPPORTED = ['en', 'zh', 'vi', 'es'] as const;
export type Locale = (typeof SUPPORTED)[number];
export const FALLBACK: Locale = 'en';

// 归一主站下发的任意 lang 值:小写 → 取主子标签(zh-CN/zh_CN → zh)→ 命中支持列表则返回,否则回退 en。
// 入参不可信(主站可能下发任意串 / 空 / undefined),恒返回合法 Locale。
export function normalizeLocale(input?: string | null): Locale {
  if (!input) return FALLBACK;
  const primary = input.trim().toLowerCase().split(/[-_]/)[0];
  return (SUPPORTED as readonly string[]).includes(primary) ? (primary as Locale) : FALLBACK;
}
```

import { expect, test } from 'vitest';
import { en } from './locales/en';
import { zh } from './locales/zh';
import { vi } from './locales/vi';
import { es } from './locales/es';

// 递归收集所有叶子 key 路径,断言四套完全一致(与 TS 类型互为双保险)。
function keys(obj: Record<string, unknown>, prefix = ''): string[] {
  return Object.entries(obj).flatMap(([k, v]) =>
    v && typeof v === 'object' ? keys(v as Record<string, unknown>, `${prefix}${k}.`) : [`${prefix}${k}`],
  );
}

test('zh/vi/es 的 key 集合与 en 完全一致', () => {
  const base = keys(en).sort();
  for (const dict of [zh, vi, es]) expect(keys(dict).sort()).toEqual(base);
});

```tsx
'use client';
import { useEffect } from 'react';
import { I18nextProvider } from 'react-i18next';
import i18n from '@/i18n';
import { normalizeLocale } from '@/i18n/config';

// 挂载时把 i18n(SSR 初始为 en)对齐到内联脚本已设好的 <html lang>(主站下发的真实语言)。
// 运行期变更由 useHostConfig 负责(见该文件)。语言变化经 react-i18next 自动重渲订阅组件。
export default function I18nProvider({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    const target = normalizeLocale(document.documentElement.lang);
    if (i18n.language !== target) void i18n.changeLanguage(target);
  }, []);
  return <I18nextProvider i18n={i18n}>{children}</I18nextProvider>;
}
```

import type { TFunction } from 'i18next';

// 后端 error code → i18n key。只收录已知 code;未知 code 不在表,回退后端原 message。
export const ERROR_KEYS: Record<string, string> = {
  GEN_FAILED: 'errors.GEN_FAILED',
  CLIPBOARD: 'errors.CLIPBOARD',
  AUTH: 'errors.AUTH',
  UPSTREAM_UNAVAILABLE: 'errors.UPSTREAM_UNAVAILABLE',
};

// 命中映射且词条存在 → 译文;否则回退后端原 message(现行行为,尊重契约不臆造)。
export function resolveErrorMessage(code: string, fallbackMessage: string, t: TFunction): string {
  const key = ERROR_KEYS[code];
  if (key && t(key) !== key) return t(key);
  return fallbackMessage;
}
