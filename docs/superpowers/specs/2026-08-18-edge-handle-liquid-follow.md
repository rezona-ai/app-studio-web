# 折叠把手液体粘连跟随 — 设计稿

日期：2026-08-18
关联：`docs/superpowers/specs/2026-08-17-sidebar-collapse-handles.md`（把手本体几何与命中口径）

## 目的

两侧边栏折叠把手（`EdgeHandle`）目前只有 opacity 淡入淡出，浮现之后是一块死的按钮。给它加一层**鼠标跟随的液体粘连**：把手是一滴贴在边栏上的液体，指针进入后往画布侧（离开边栏的反方向）移动时，**整滴液体被牵引变形**——轮廓上每一点都在动，贴边的浸润线随之收缩；指针走过张力作用长度，张力拉不住，液体脱手弹回原形。

## 三条硬要求（本轮由 Nick 明确，凌驾于其它设计偏好）

1. **整体形变，不是突出一块**。轮廓上每一点都参与，含贴边那条线；不允许"本体不动、局部拽出一个东西"。
2. **图标内容完全不受影响**。动效期间 chevron 不位移、不缩放、不淡出，就是它原来的样子。
3. **粘连还在，点击就能正常触发按钮功能**。指针被液体粘着的整个过程中，任何时刻按下都要等同于点了那个折叠按钮。

## ⚠️ 前两版为什么废掉（勿重蹈）

- **v1「本体不动 + 独立液滴 + goo 细颈」**：读起来是"把手旁边挂了个东西"，不是把手自己在变。违反要求 1。
- **v2「凸边中段拽出一条舌头」**：把手上下两端纹丝不动，仍然是"突出一块"；且图标做了衰减跟随（违反要求 2），指针拉远后落在 24px 命中区外，点击点不到（违反要求 3）。
- 两版共同的病根：**把形变当成局部装饰**，而不是"整滴液体的形状函数"。

## 形变模型：位移场

把静态轮廓离散成一圈采样点，对每个点施加一个**位移场**，再用闭合 Catmull-Rom 重建平滑轮廓。整体感来自"每个点都有自己的位移"，而不是某一段被特殊对待。

牵引点 `T = (tx, ty)`：指针在液体层局部坐标里的位置。横向夹在画布侧（往边栏侧不形变），**纵向恒等于指针真实位置、不做夹取**——夹了它就不再是指针所在，命中圆罩不住指针（见坑 1）。
对轮廓上每个点 `P`：

| 分量 | 公式 | 作用 |
|---|---|---|
| 边缘因子 | `e = P.x / HANDLE_W` | 贴边（x=0）为 0 → **浸润线不离开边栏**；凸边为 1 → 拉得最多 |
| 横向权重 | `w = (1+LOBE)·flatTop(d,σx) − LOBE·g(d,σ_lobe)`，`d = |P.y − ty|` | 主瓣**平顶**（`exp(−(d/σ)⁴)`）→ 峰顶是一段平台 = **圆头**；负瓣宽而缓 → 中段收腰、**远端转负使上下两端内收** |
| 横向位移 | `Δx = (tx − HANDLE_W)·e·w·strength` | |
| 纵向位移 | `Δy = (ty − P.y)·g(d,σy)·DRAW_Y·**stretch**·strength` | **不乘 e** —— 贴边那条线也跟着朝牵引点聚拢，浸润线因此变短，这是"整体在变"的关键一笔；但**必须乘 `stretch = pull/REACH`**，否则没拉动也满额收拢（见坑 3） |

- `g(d,σ) = exp(−(d/σ)²)`；`flatTop(d,σ) = exp(−(d/σ)⁴)`。
- `strength`：拉扯期恒 **1**（见下"为什么不做跟随惯性"），脱手回弹期由 `easeOutBack` 从 1 送回 0 并**过冲成负** → 位移反向 = 回弹那一下的反向内凹。
- `strength = 0` 时位移全为 0，轮廓精确等于采样点本身 = 静态轮廓。

### 为什么不做跟随惯性（lerp）

要求 3 要「粘连期间点击恒可用」，而可用的前提是**指针处必须有命中区**。若给形变加惯性，轮廓头部会滞后于指针，指针经常落在轮廓外。故拉扯期 `strength ≡ 1`、牵引点 1:1 跟手，**液体感全部做进形状**（收腰、远端内收、浸润线收缩、圆头），惯性只留给脱手回弹。

## 渲染与命中（三层，自下而上）

```
定位容器 (现有, pointer-events-none, w=24, inset-y-0, z-30)
├── ① 液体视觉层   div, pointer-events-none, clipPath = 形变轮廓, bg = --color-pop
├── ② IconButton   **尺寸/位置/图标一律不动**(24×132, clipPath 静态轮廓);
│                   活性态背景转透明(色块交给①)、opacity 强制 100(它已被③盖住,收不到 :hover)
├── ③ 轮廓命中层   div, pointer-events-auto, 透明, clipPath = 形变轮廓（与①同一条）, onClick = 折叠
└── ④ 指针命中圆   div, pointer-events-auto, 透明, 圆形, 跟随指针定位, onClick = 折叠
```

**要求 3 的落点是③+④**。轮廓头部在牵引点落在凸边范围外时（`e < 1`）伸不到指针，此时只认可见轮廓就点不到；④这个跟随指针的隐形小圆保证指针底下**恒有**命中区。二者只在粘连期间存在，脱手即消失。

④**必须是独立元素，不能并进③的 clipPath**：拉到最远时牵引点正落在液体层的边缘，并进去的话圆的外半圈超出 border box 被裁掉，**恰好拉满时反而点不动**（已踩，见坑 2）。

**要求 2 的落点是②整条不动**：按钮尺寸不变（否则 Tooltip 会以变宽后的 rect 居中而跑偏——`Tooltip` 只在展开那一刻测一次 rect），图标不加任何 transform。

## 交互状态机

```
idle ──pointerenter 按钮本体──▶ pulling（挂 window pointermove + rAF，strength ≡ 1）
                                  │
      指针在画布侧移动 ───────────┤ 牵引点 1:1 跟手，整滴液体随位移场变形
      指针回到边栏侧 ─────────────┤ 牵引点回到外缘，形变归零，仍为 pulling
                                  │
      dx > REACH ────────────────▶ released：脱手，320ms easeOutBack 收回（中途反向内凹）→ idle
      |dy| > HANDLE_H/2 / 退回边栏内侧够深 / 点击 / 卸载 ▶ idle（清监听）
```

脱手后须重新 `pointerenter` 本体才再次触发（否则在画布上晃悠会反复粘上又脱开）。③消失后指针不移动不会重新 hit-test，天然满足。

## 纯函数（`src/lib/edge-handle.ts`，全部单测）

```ts
export const HANDLE_REACH = 44;                   // 横向拉伸行程上限
export const LIQUID_W = HANDLE_W + HANDLE_REACH;  // 液体层宽度

/** 指针位移 → 牵引点(液体层局部坐标)；超出张力作用长度 / 退回边栏内侧够深 → null = 脱手 */
export function tension(dx: number, dy: number): { tx: number; ty: number } | null;
/** 形变后的闭合轮廓；strength=0 时精确等于静态轮廓，strength<0 为回弹过冲的反向内凹 */
export function liquidPath(tx, ty, strength, side): string;
/** 指针处隐形命中圆的落位（独立元素，不受液体层 box 裁剪） */
export function hitCircle(tx, ty, side): { size: number; top: string; left?: number; right?: number };
```

右侧把手由这几个函数内部按 `x → LIQUID_W − x` 出镜像版（**不**用 CSS `scaleX(-1)`——那会把②里的图标一起镜像，撞上要求 2），镜像关系由单测守护。

### 数值

| 常量 | 值 | 说明 |
|---|---|---|
| `HANDLE_REACH` | 44px（≈1.8 倍身宽） | 横向拉伸行程上限；牵引点 1:1 跟手直到脱手。表面张力偏强、粘一小段就脱手。迭代过 110（4.5 倍，整滴被抻成细长三角旗）→ 88（3.7 倍，仍偏长且粘太久会一直吃掉画布点击）→ 44 |
| `σx` | 32px（**平顶** 4 次方高斯） | 主瓣宽度，决定头有多宽。平顶是圆头的来源——普通高斯峰顶只有一个点够得到牵引点，轮廓会读作一根尖刺 |
| `σ_lobe` / `σy` | 55px / 60px | 负瓣宽度（决定腰收在哪儿）/ 纵向收拢宽度（取大是为了让**贴边线的两端也动起来**） |
| `LOBE` | 0.15 | 负瓣系数：腰与两端内收的幅度 |
| `DRAW_Y` | 0.3 | 纵向朝牵引点收拢的强度 |
| `HIT_R` | 14px | 指针处隐形命中圆的半径 |
| 采样点 | 74（两段曲线各 20 / 凸边 20 = 间隔 3px / 贴边 14） | 凸边间隔决定头部欠冲（见坑 10）；贴边稀疏无妨，共线点重建仍是直线 |
| 脱手回弹 | 320ms `easeOutBack`（back 1.2），内凹下限 `strength ≥ −0.08` | |

## 已知坑

1. **脱手判据两轴分开判，别用欧氏距离**：纵向移动是手指沿液面滑、并不拉伸液体，算进距离会让稍微斜一点的拉扯提前脱手（实测斜拉 45px 就断）。横向超行程才是拉断，纵向超出把手高度的一半算滑出横带。这条同时保证 `ty` **不需要夹取**——牵引点一旦被夹就不再等于指针真实位置，命中圆罩不住指针，要求 3 立刻失效。
2. **纵向位移必须乘归一化拉伸量 `stretch`**：横向有 `pull` 兜着"没拉就不动"，纵向没有。漏了它，指针刚碰上把手、什么都还没拉的那一瞬整个把手就被压矮一截（实测 132 → 120.2），读作"聚焦时高度突然变小"。因为 `strength` 一进入牵引态就是满值（为要求 3 特意去掉了惯性），这个跳变是瞬时的、非常明显。已踩。
3. **命中圆不能并进 clipPath**：`clip-path` 只在元素的 border box 内生效，拉满时牵引点正在液体层边缘，圆有一半被裁 → 恰好拉满那一下点不动。做成独立定位的圆 div 就不受 box 约束（已踩，行程减半后才在边界上暴露）。
4. **别给形变加惯性**：头部滞后 → 指针落在轮廓外 → 点击失效（撞要求 3）。
5. **别改按钮尺寸**：`Tooltip` 只在展开瞬间测一次 rect，按钮变宽会让气泡跑到形变体中间。
6. **别用 CSS `scaleX(-1)` 做右侧镜像**：图标在同一棵子树里会被一起镜像（撞要求 2）；镜像做在几何函数里。
7. **活性态按钮要强制 `opacity-100`**：它被③盖住收不到 `:hover`，仍挂在 `hover:opacity-100` 上的话图标会直接消失。
8. **按钮底色只能由 `shape` 决定，不许 `:hover` 参与**：`:hover` 是即时的，而液体层要等 `onPointerEnter` → `setState` → 重渲染才出现，中间差一帧。让 `:hover` 掺进底色，这一帧必然露馅，且两种写法各露一种：挂着 ghost 自带的 `hover:bg-[var(--color-fill)]` 是**一闪而过的高亮**（fill 比 pop 亮），无条件 `hover:bg-transparent!` 则是**只剩图标的空窗**（脱手后快速回粘时最明显）。两个都已踩，rAF 逐帧采样才抓得到。正解是 `shape ? 'bg-transparent!' : 'bg-[var(--color-pop)] motion-safe:hover:bg-[var(--color-pop)]!'` —— 切换两侧同为 pop 色 + 同一条静态轮廓（`shape` 刚建立时是 REST），错位帧因此不可见；`motion-safe:` 分流保证 `reduce-motion` 下液体不启动时仍有悬停反馈。
9. **负瓣必须在 d=0 处归零**：写成 `g − LOBE·g2` 时 d=0 得 `1−LOBE`，头部够不到指针；正确形式是 `(1+LOBE)·g − LOBE·g2`。
10. **`easeOutBack(p)` 是 0→1 的进度**，回弹要的是"还剩多少"，必须取 `1 − 它`；直接乘会让形变在脱手瞬间归零、根本没有回弹（v2 已踩，逐帧采样才发现）。
11. **别用 `max(x)` 判内凹**：轮廓里凸边点的 x 会占住最大值，内凹要看**非零 x 的最小值**。
12. **Catmull-Rom 的控制点会被邻点带到负半轴**（实测 −0.02），曲线随之微微越过边栏。输出前把 x 夹到 ≥0，用构造保证"液体不离开边栏"而不是靠容差。
13. **凸边采样间隔决定头部欠冲**：牵引点落在两个采样点正中时头到不了指针（间隔 6px 差 1.8px，3px 差 0.25px）。取 3px。
14. **`prefers-reduced-motion` 要在组件内 `matchMedia`**，CSS 媒体查询关不掉 `pointermove` 与 rAF。
15. **指针退回边栏内侧也要收场**：停在边栏上永远够不着张力作用长度，不收则 rAF 一直空转。
16. **底色 `--color-pop` 与画布底、与卡片都相近，光靠它立不住**：把手压在卡片上、或对话栏收起后贴着视口左缘时几乎看不见，失去引导作用。解法是 `--elev-edge-handle`（globals.css）——两层 `drop-shadow`：近距发丝勾边 + 一层落影，深色稿的发丝取白、浅色稿取黑，与 `--shadow-popover` 的分层语汇一致。
17. **clipPath 元素加不了 `box-shadow` / `border`**：阴影落在裁剪区外会被一并裁掉，边框也不会沿曲边走。**只能用 `filter: drop-shadow()`** —— 它作用于裁剪后的渲染结果。挂在**定位容器**上而不是按钮上：这样静态态（按钮的 clipPath）与牵引态（液体层的形变轮廓）共用一份，投影自动跟着形变的曲边走；全透明的命中层不参与投影。
18. **`drop-shadow` 没有 spread 参数**，做不出 `box-shadow` 那种 `0 0 0 1px` 的实描边。要一圈实发丝得**四个方向各来一层 0 模糊的 1px 偏移**，末层再叠落影。
19. **深色稿的落影等于没有**：黑影铺在深画布底上不可见（`--shadow-popover` 那条注释里是同一个道理），深色稿的抬升**全靠亮发丝**；浅色稿则是描边 + 落影双管齐下。
20. **发丝强度试错了三轮，最后定在 0.16（与 `--shadow-popover` 的 0.12 同一档）**：`0 0 0.6px` 的单层柔光晕 → filter 开关对照看不出差别；加到 **0.42** → 变成一条生硬白线，被判"突兀、很丑"；`0 0 3~4px` 的柔光晕 → 又回到看不见。**这套深色稿的分层本来就靠极淡发丝，加粗加亮反而出戏** —— 存在感不够时先怀疑别的手段（提亮本体底色等），别去加粗发丝。

## 成功标准

1. 拉扯时**轮廓上每一点都在动**：凸边被拉出圆头、上下两端内收、贴边浸润线朝牵引点收缩变短。
2. 图标全程零位移、零缩放、零透明度变化。
3. 粘连期间任意时刻点击都触发折叠 / 展开（含指针已远离原 24px 区域时）。
4. 往边栏侧移动不产生形变；轮廓上任何点的 x 恒 ≥ 0（不穿进边栏）。
5. 走过 `HANDLE_REACH` 后脱手回弹，中途可见反向内凹；须重新进入本体才再次触发。
6. 静态 / Chat 收起常显态的把手渲染与改动前一致。
7. 非粘连期间画布点击、框选、拖拽、缩放零变化。
8. `prefers-reduced-motion: reduce` 下整套关闭。
9. 左右两侧共用同一实现，镜像由单测守护。
10. `pnpm lint` / `tsc` / `pnpm test` / `pnpm build` 全绿。

## Minor / 暂不做

- 键盘 focus 态的形变（无指针坐标，物理语义不成立）。
- 触摸设备：`pointermove` 要按下才有，实际不触发，不专门适配。
