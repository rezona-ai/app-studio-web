# i18n 扩充到 11 语（设计稿）

日期：2026-07-15 · 分支：feat/i18n-expand-11-locales

## 背景与目标

现有 i18n 为六语（en / zh / fr / ru / ja / vi）。主站语言菜单已扩充为 11 语，分站需对齐（顺序同主站菜单）：

| 顺序 | 母语名 | locale 码 | 现状 |
|---|---|---|---|
| 1 | English | `en` | 已有（fallback，单一真相源） |
| 2 | 简体中文 | `zh` | 已有（菜单母语名由「中文」改为「简体中文」） |
| 3 | 繁體中文 | `zh-TW` | **新增** |
| 4 | Deutsch | `de` | **新增** |
| 5 | Español | `es` | **新增** |
| 6 | Français | `fr` | 已有 |
| 7 | 한국어 | `ko` | **新增** |
| 8 | Português | `pt` | **新增** |
| 9 | Русский | `ru` | 已有 |
| 10 | 日本語 | `ja` | 已有 |
| 11 | Tiếng Việt | `vi` | 已有 |

## 关键设计点

### 归一规则升级（`normalizeLocale`）

现规则「小写 → 取主子标签」会把 `zh-TW` 折叠成 `zh`（简体），繁体用户会被错切到简体。升级为**先全标签匹配、再繁体别名、后主子标签**：

1. 小写、`_`→`-` 归一后**先精确匹配支持列表**（`zh-tw` → `zh-TW`）；
2. 繁体常见别名归并：`zh-hant` / `zh-hk` / `zh-mo` → `zh-TW`；
3. 否则取主子标签匹配（`pt-BR` → `pt`、`de-AT` → `de`、`zh-CN` → `zh`）；
4. 未命中回退 `en`。

不变式保持：入参不可信，恒返回合法 `Locale`。

### 词典加载

沿用「仅 en 静态打包、其余动态 import 独立 chunk」结构，`localeLoaders` 增补五个显式静态映射。新词典文件命名与 locale 码一致：`zh-TW.ts`（导出 `zhTW`）、`de.ts`、`es.ts`、`ko.ts`、`pt.ts`，均标注 `: Messages`，缺 key 编译期报错。

### 语言菜单（`LanguageMenu`）

`LANGS` 扩到 11 项、顺序同主站菜单；`zh` 母语名改「简体中文」、新增 `zh-TW`「繁體中文」。触发钮短码：EN / ZH / TW / DE / ES / FR / KO / PT / RU / JA / VI。

## 不做的事

- 不改主站下发协议（`taluna-config` 的 `lang` 仍为任意串，靠归一兜底）；
- 不改「首帧恒 en」与按需加载行为；
- 不给游戏内容做多语（仅平台 UI 文案）。
